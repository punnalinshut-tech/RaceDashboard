# Real-time Race Dashboard

## Project Overview
ระบบแสดงผลการแข่งขันแบบ Real-time พัฒนาขึ้นเพื่อสนับสนุนการแสดงผลการแข่งขันภายในกิจกรรม โดยสามารถรับส่งข้อมูลระหว่างคอมพิวเตอร์ผ่านเครือข่าย LAN และแสดงผลผ่าน Dashboard

## Technologies Used
- Python
- FastAPI
- HTML, CSS, JavaScript
- Microsoft Excel
- LAN Network

## Key Features
- รับส่งข้อมูลการแข่งขันระหว่างคอมพิวเตอร์
- แสดงผลข้อมูลการแข่งขันผ่าน Dashboard
- รองรับการอัปเดตข้อมูลจากเครื่องส่งข้อมูล
- แสดงผลการแข่งขันตามประเภทและรุ่นการแข่งขัน

## Testing
- Functional Testing: ตรวจสอบฟังก์ชันการทำงานของระบบ
- Integration Testing: ตรวจสอบการเชื่อมต่อระหว่างเครื่องส่งและเครื่องแสดงผล
- Data Validation: ตรวจสอบความถูกต้องของข้อมูลจาก Excel
- Connectivity Testing: ทดสอบการรับส่งข้อมูลผ่าน LAN

## Development Approach
พัฒนาระบบโดยใช้ AI เป็นเครื่องมือช่วยในการเขียนและปรับปรุงโค้ด ร่วมกับการกำหนดความต้องการ ทดสอบ และแก้ไขข้อผิดพลาด เพื่อให้ระบบสามารถทำงานได้ตามวัตถุประสงค์
